# 生命周期 Lifetime

生命周期是编译器用来**保证引用有效**的机制。

## 核心规则

- 每个引用都有生命周期
- 编译器在大多数情况下可以自动推断(省略)
- 返回的引用必须与输入参数的某个生命周期相关

## 显式标注

```rust
fn longest<'a>(x: &'a str, y: &'a str) -> &'a str {
    if x.len() > y.len() { x } else { y }
}
```

## 结构体中的生命周期

```rust
struct Excerpt<'a> {
    part: &'a str,
}
```

## 小结

| 概念 | 一句话 |
| --- | --- |
| 所有权 | 值只有一个所有者 |
| 借用 | 不转移所有权地使用 |
| 生命周期 | 引用保持有效的时间范围 |

> 三个概念互相配合,构成 Rust 内存安全的基础。
